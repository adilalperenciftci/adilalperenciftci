# Adil Alperen Çiftçi

I build security research tooling for software-supply-chain assurance, endpoint telemetry, and controlled adversary validation. My work emphasizes explicit authorization boundaries, deterministic evidence correlation, fail-closed verification, and reproducible local laboratories.

## Security research

- [Runtime Provenance Firewall](https://github.com/adilalperenciftci/runtime-provenance-firewall) — correlates Linux runtime evidence, execution graphs, artifact digests, SLSA provenance, attestations, and policy decisions.
- [Enterprise Purple Range](https://github.com/adilalperenciftci/enterprise-purple-range) — an isolated Active Directory research range for endpoint, identity, and network evidence correlation.
- [Adversary Validation Range](https://github.com/adilalperenciftci/adversary-validation-range) — reproduces controlled attacks against deliberately vulnerable local targets and validates detections against attack and benign evidence.
- [Agent Boundary](https://github.com/adilalperenciftci/agent-boundary) — local-first policy enforcement and forensic telemetry for AI-agent and MCP tool boundaries.
